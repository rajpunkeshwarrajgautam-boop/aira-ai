# AIRA AI — Product Context

AIRA AI is a research and execution workspace for people who want one place to ask grounded questions, run deeper research, use autonomous agents, retain useful memory, and manage usage.

## Product lane
Product application / AI workspace. Not a marketing site.

## Primary jobs
- Ask questions and receive grounded answers with citations.
- Continue research in persistent conversations.
- Run autonomous agent tasks.
- Review and manage persistent memory.
- Understand plan and usage limits.
- Navigate quickly between research, agents, memory, pricing, and owner analytics.

## Audience
Power users, operators, founders, researchers, and technical users who value speed, evidence, and control.

## Product voice
Precise, calm, operational, capable. Prefer direct labels and useful state over promotional language.

## UX principles
- The active task owns the visual hierarchy.
- Navigation stays persistent but quiet.
- Evidence and status remain legible.
- Avoid fake features and decorative controls.
- Prefer keyboard-accessible workflows.
- Progressive disclosure over dense control walls.
- Responsive layouts must preserve core actions on mobile.

# AIRA AI — UX & Viewport Acceptance Matrix

Every user surface must operate flawlessly across 5 target responsive viewports:
- **360px**: Small mobile (compact drawer, single-column feed, tap targets >= 44px)
- **390px**: Standard mobile (iPhone standard)
- **768px**: Tablet portrait (collapsible navigation rail)
- **1024px**: Tablet landscape / Small laptop
- **1440px+**: Desktop workstation (full persistent rail, multi-pane canvas)

Keyboard Accessibility:
- `Ctrl/Cmd + K`: Global Command Palette
- `Esc`: Dismiss modal / drawer / active focus
- `Tab / Shift+Tab`: Visible accessible focus rings
